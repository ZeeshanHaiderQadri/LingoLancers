# Lingo Design System Direction

## Interface character

Mission Control is a calm operational workspace for a founder reviewing live work at a desk during the day. Use a light, warm-neutral surface with one deep violet action color and clear semantic states.

## Tokens

- Background: warm off-white neutral
- Surface: slightly cooler neutral for navigation and controls
- Accent: deep violet, reserved for primary actions and active selection
- Status: green for completed, amber for approval needed, red for failed, blue-grey for running
- Typography: Inter or system sans, compact and highly legible

## Layout

- Persistent side navigation on desktop, collapsible navigation on smaller screens.
- A mission page leads with the objective and current decision, then a chronological event timeline.
- Evidence, artifacts, approvals, and cost are secondary panels, not a grid of equal cards.
- Empty states must explain the next useful action.
